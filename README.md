A simple weather forecasting web application that allows users to check whether it will rain tomorrow by entering a city name. The application fetches weather data from a weather API and displays the forecast in a clean and responsive interface.

## 🌐 Live Demo

[🔗 SkyScanner Live](https://skyscanner-2vu6.onrender.com)


🚀 Features
Search weather by city name
Rain prediction for the next day
Responsive user interface
Fast and user-friendly design
Error handling for invalid city names
